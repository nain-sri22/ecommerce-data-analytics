# E-Commerce Data Analytics

An end-to-end data analytics project using **MySQL and Power BI** to analyze e-commerce sales, customer behavior, product performance, orders, payments, shipping, and inventory.

## 📌 Project Overview

This project transforms e-commerce data into meaningful business insights using SQL analysis and an interactive Power BI dashboard.

The analysis focuses on:
- Sales and revenue performance
- Customer and order analysis
- Product and category performance
- Payment and shipping patterns
- Inventory and low-stock analysis
- Customer spending behavior

## 🛠️ Tools & Technologies

- **MySQL** – Database management and SQL analysis
- **Power BI** – Data modeling, DAX and dashboard visualization
- **Microsoft Excel** – Data handling and supporting analysis

## 🗄️ Database

The MySQL database contains multiple related tables, including:

- Customers
- Categories
- Products
- Sellers
- Inventory
- Orders
- Order Items
- Payments
- Reviews
- Shipping

## 📊 Power BI Dashboard

The Power BI dashboard contains four analytical pages:

### 1. Executive Overview
Provides a high-level view of overall business performance through key KPIs and sales trends.

### 2. Product & Category Analysis
Analyzes product performance, category revenue, ratings, and inventory levels.

### 3. Customer & Order Analysis
Examines customer spending, order status, payment methods, and shipping status.

### 4. Sales & Financial Analysis
Focuses on revenue trends, category-wise revenue, ratings, and monthly order performance.
